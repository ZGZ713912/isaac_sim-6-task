# 历史静站与当前趴地训练的配置复核（2026-10-27）

旧版确实实现过305mm短时静止站立。这轮趴地训练没有保留并复现其完整训练配置。此前把新目标称作“正常静站奖励”，没有明确它与历史成功目标不同，该表述不准确。

| 对照项 | 历史静站009 | 当前趴地007 |
|---|---|---|
| 起点与任务 | 305mm站姿，零运动命令 | 正常朝上、底盘贴地，被动落稳后学习起立 |
| 实际行为 | 305mm、8秒冷测7/7通过；最大XY 1.558cm | 起立0/21；1秒后高度中位200.049mm、倾角14.015°；全部在首次位移超过0.5m时终止 |
| 静站目标 | precise-standing-reward-v2-coupled；姿态×高度×静止速度，共同满足最高12/s | 新upright_locomotion加法目标，加最高4/s联合静站奖励、宽高度成本、时间/位移成本及势能引导；没有启用历史precise目标 |
| 轮子动作 | 编码器轮速＋学习增量 | 直接学习绝对轮速目标 |
| 神经网络腿速度路径 | LegVelocitySeparatedModel | 普通MLP；未启用分离结构 |
| 初始化 | 名义静力承重推导的可训练输出bias | 预抬升几何推导的可训练输出bias |

| 域随机化 | 009名义参数；后续013另做逐步学习人口准入 | v2强度0.25，从本轮开始参与 |
| 完成训练量 | 512更新×256环境×128步；名义采样16,777,216条 | 128更新×256环境×256步；名义采样8,388,608条 |

两者物理PD都保留真实腿速度反馈，均为200Hz策略、1kHz物理/PD。旧版的神经网络结构不等于冻结腿或去掉物理D反馈。采样条数为计划采集量，不能代替实际有效PPO样本账本。

旧009轮材料摩擦0.1、地面0.5，平均组合约0.3；当前采用更高轮材料摩擦。因此已有证据不支持“摩擦低导致根本站不住”作为唯一解释；趴地起立对接触与摩擦的需求仍须单独验证。

当前全部128个TensorBoard更新的stable_fraction为0，联合静站奖励实付的rollout均值最高约2.316e-7/策略步、最后约5.193e-10/步。可以确定该新策略没有建立站稳行为；不能仅凭这些结果量化奖励、动作接口、课程、训练量和随机化各自的因果贡献。静站奖励从趴地开始几乎拿不到，不能用函数存在或奖励项名称代替旧站立课程的复现。

历史013还提供同一准确权重的305mm名义8秒7/7证据；指定域计入既定XY≤5cm后为5/7，其中实际随机6台为4/6。009/013的低高姿态、完整30秒、全部13项与实车能力不能据此授予通过。不同代际成绩不拼接。

纠正方向是复用经过验证的站立配置，在同一次全新actor/critic/空Adam训练中先建立站稳，再逐步增加趴地起立与分组域随机化，并持续保留静站复习；全过程维持用户要求的约10cm起立范围、IMU水平、速度/角速度和平顺验收。从零要求不妨碍复用配置及同一轮内部课程，禁止读取旧权重/teacher/donor的约束保持。
