# 静站位置观测的离线 C++ 候选

这些文件只完成了独立数值回放，尚未接入 RMCS，也不是可直接替换旧模型的部署包。

`standing_reference_v3.hpp`只生成观测，不生成腿或轮命令。输入为107模型连续关节角，顺序为左髋、左辅助、右髋、右辅助、左轮、右轮，以及同一次策略采样的35维观测。轮角须已经完成减速比和轴向转换。几何表与训练使用的冻结表一致，SHA-256见`model_geometry107.hpp`和`../deployment_cpp068.json`。

接口的时间约定固定为200 Hz。每个策略tick调用`sample()`，重复读取相同tick不重复滤波；输出的两维单位为米，乘20后放入obs14:16。滤波时间常数150 ms，捕获等待50 ms，范围±0.25 m。它实现了当前模型启用的stance-aware和shape-aware门；不能用于其他门配置。

在整体reset、策略重新进入或标定坐标改变时调用`reset()`。运动请求结束静站参考；严重倾斜时丢弃旧参考，并等待有效直立、低角速度、合适腿形和指定时间后重建。短时无效输入保留参考并输出零。有效几何、重复tick、空转、NaN、运动切换和严重倾斜的回放结果见`../deployment_cpp068.json`。

后续接入须由`WheelLegController`持有状态，维持现有PD、标定、安全和六电机输出所有权。`RlBridge`继续负责YAML观测路由及推理。还需验证策略采样时钟和传感器快照、reset路径、模型合同拒绝测试及新YAML路由。当前35,158帧检查使用了原生轨迹构造的编码器输入和人工生命周期序列；旧轨迹没有保存延迟后的原始轮角，因此不能把它称为硬件原始传感器回放或部署闭环验证。
