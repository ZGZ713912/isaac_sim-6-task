# 当前实现与建议的全局课程

检查分支：dev/leg-friction-v202-20261031，恢复课程实现提交04fcf6a7。

## 当前代码实际执行的安排

| PPO更新数/事件 | 当前行为 |
| --- | --- |
| 0–999 | 角色池保持30%恢复、25%静站和其他运动/高度角色；运动与高度指令幅度为零，因此同时学习站立与正向自起，并非纯URDF姿态静站阶段。 |
| 1000起 | 前后直行、四向弧线、自旋、静止高度的指令幅度按同一全局更新数分别渐入。它们未按独立能力评测解锁。 |
| 5000 | 静止高度指令达到完整范围。 |
| 6000 | 前后直行达到±2m/s；弧线前后速度达到±2m/s、yaw达到±0.6rad/s。 |
| 7000 | 双向自旋指令达到100rpm。 |
| 四种正向腿组合全部通过 | 恢复池从100%正向倒地变为60%正向、40%复杂倒地。不会在2000轮自动解锁。 |
| 通过后再2500次更新 | 恢复池变为40%正向、60%复杂倒地，四腿组合始终分别覆盖。 |
| 10000 | 唯一正式训练预算结束，不因未通过门槛自动延长。 |

恢复门槛默认每250次更新检查，每类4次独立留出试验，四类成功率分别达到100%，且每次实际自起完成后连续站稳3秒。这个门槛仅用于课程准入。

当前高度角色针对静止变高度；运动和自旋角色目标高度保持305mm。行驶、转弯、自旋同时变高度的组合课程尚未接入，不能由静止高度或固定高度运动的测试代替。

## 建议的最终全局课程（尚未实施）

| 阶段 | 主任务 | 解锁关系 |
| --- | --- | --- |
| 1 | URDF名义关节姿态，双轮接地，305mm静止站立 | 从零学习，无复杂倒地或非零运动指令。 |
| 2 | 正向倒地四种腿组合自起；静止变高度 | 静站通过后加入，持续复习静站；四种腿组合独立评测。 |
| 3 | 复杂倒地翻正→自起；低速前进/后退、启停 | 复杂倒地依赖四类正向通过；低速运动依赖站立，可与复杂倒地并行。 |
| 4 | 低速四向转弯、双向低速自旋 | 先掌握低速直行及启停，运动目标与yaw分别渐进。 |
| 5 | 更高速前后移动、转弯、自旋及高速制动 | 各自对应低速技能通过后提高幅度；最终目标保留±2m/s和双向100rpm。 |
| 6 | 全能力混合复习及逐级域随机化 | 常驻站立、自起和已通过的运动技能，最终仍为同一次10000轮从零训练。 |

高度是一条逐层叠加的分支：站稳后练静止变高；静止变高与低速行驶均通过后练低速行驶变高；转弯或自旋的基础技能通过后加入对应变高；高速组合最后加入。不把所有高度训练推迟到高速之后，也不在基础动作未学会时同时叠加全部要求。

以上是建议的全局依赖顺序，不能把它当作已经执行的课程。具体阶段轮数由评测决定，10000轮是总预算；不应承诺固定某轮必然学会，也不自动追加训练。

## 独立旧模型评测

旧v4第2500轮模型在已辨识腿摩擦的新环境中做了16次冷评测。双前0/4、双后1/4、左前右后0/4、左后右前0/4，未满足四类门槛；这是特定旧模型跨摩擦迁移的结果。恢复了actor、critic及17份Adam状态并逐值核对，但新optimizer更新为0，没有进行续训。完整结果见continuation_assessment001/baseline_mastery.json与receipt.json。

最终正式训练不读取这些权重；独立研究续训入口及产物具有单独来源标记。旧模型评测不提供新训练策略、长期稳定性或实车资格。
