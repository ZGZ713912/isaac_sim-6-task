# 本机 2560 更新后的动作与奖励信用诊断

pilot013 完成同 v6 合同的 256 更新，全谱系 2560、全部实验消费 3648、剩余 16352。eval013 保持原八场景、种子 290929、四副本、10/16 秒和 1 秒 warmup；初始及 2304 模型完整 payload 精确复现 eval012。当前 32 回合跑满，仍仅反向 yaw 通过，严格 1/8。前进 +0.5 实速约 +0.0515 m/s，反向 -0.5 约 -0.0180 m/s；三档高度仍约 0.31 m。数值、回合长度和机械稳定性不构成长训资格。

既有 actuation001 证明 2304 模型附近六轴存在局部物理响应，credit_probe005 证明原生离散事件及连续密度实付。它们尚未直接测量：在当前固定命令下，能够改变速度或高度的小动作，其原生总收益是否被其他代价抵消。此次先检查这一假设，不增加 PPO、不改任何训练合同。

复用 `scripts/diagnose_local_actuation.py` 的独立进程协议、eval013 当前 2560 模型和本段冻结物理源码。32 个原固定初态，前 200 帧共同前缀，随后单个 policy 轴 ±0.1，100 ms 渐入、900 ms 保持、100 ms 渐出，再恢复原闭环 actor，合计 600 帧/3 秒。腿偏置 ±0.025 rad、轮目标偏置 ±1 rad/s，原限幅、力矩帽、3 mm 机械门保持。首先对无干预的旧记录模式与新增 `--reward-credit` 模式做完整初态/RNG及全部旧 600 帧数组逐位核对；再对 baseline 与六轴正负共 13 臂核对所有干预前数组。不宣称冷启动等于原顺序评测。

新模式只记录原生逐环境 reward、连续奖励密度、返回的 critic 观测和终止标记，不额外读取机器人状态、不调用优化器。完整状态和全部失败保留。由原生 reward 减去密度乘 dt 得到的离散部分需要与实际终止对照；不能把 reset 后观测当终止前状态。actor/critic 不变、Adam 为空，训练时钟和消费不推进。

逐场景报告干预后的原始及折扣 reward 差、各密度贡献、速度/角速度/高度响应、所有终止和限幅。可用精确保存的当前 critic 在 CPU 对现有观测计算端点值，单独报告带端点估计与不带端点估计的结果；终止后的 reset 状态不 bootstrap。有限 3 秒窗口和估计 critic 都不等于完整策略梯度或重新训练效果。四副本的描述性差分不能扩称跨种子证据。

派生指标接入 pilot013 原 RSL-RL event 的 `LocalDiagnostics/ActionCredit`，固定 step2560，单位明确；原始 NPZ、manifest 和 SHA 继续作为回执。原生测量中发现异常时保留负结果并诊断，不放宽验证器。根据结果再提出明确、有限、保留全部学习状态和消费的训练修订；不能直接用低 std、存活或单项成本为继续大训背书。
