严格探针验证器现在也显示保存的原始异常。原始失败目录保留，未跳过探针，

## 启动命令

`run001.native_probe`已有失败证据，使用当前确认不存在的run002目录：

```bash
cd /root/gpufree-data/workspace/prone_motion_long
WHEELED_RL_PYTHON="$PWD/scripts/server_isaac_python.sh" \
  bash scripts/train_prone_motion.sh --output "$PWD/runs/prone_motion/run002"
```

没有恢复任何旧训练。若输出目录已被另一次启动创建，应另选新目录并保留原证据。
