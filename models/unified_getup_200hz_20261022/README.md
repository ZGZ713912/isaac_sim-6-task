# 200 Hz 全 RL 起身与运动候选

`policy.onnx` 是 1×35 → 1×6 的确定性均值策略。本候选先测试 305 mm；高位强随机化静站仍失败。具体结果、SHA 和通道约定见 `deployment_contract.json`。

`checkpoint.pt` 保留本次导出来源；`inference_vectors.json` 提供真实观测与预期 raw action，可先在运行端做离线数值对照，再由用户启动实车。

在具备 NumPy 和 ONNX Runtime 的环境运行 `python verify_export.py` 可核对 SHA、形状、动作范围和冻结推理向量；该脚本只做离线推理。

腿动作乘 0.25 后是相对名义角的偏移，表示范围为 ±4 rad；轮动作乘 10 后为 ±90 rad/s。当前读取的 RMCS `rmcs_rl/src/policy.hpp` / `action.cpp` 仍将腿 raw action 限为 ±3（偏移 ±0.75 rad），会截断起身动作；运行端需要支持本合同的 ±16。用户已确认实际策略为 200 Hz；同时核对代码中仍为 50 Hz 的旧常量及其派生周期，确保本策略每 5 ms 执行和更新历史。保持 paired_branch107_v1 成对换绕与闭链投影、160/2.5 反馈 PD、1000 Hz PD 和既有真实力矩/新鲜度保护。35 维观测中的腿角必须按相对名义角绕回 ±π。

全 RL 入口需要在失能阶段保留气弹簧、六电机零力矩；使能首帧用测得腿角作成对共同角换绕，除以 0.25 播种动作历史，轮历史置零。之后每个 5 ms 输入上一帧导出的 raw action，不能输入加比例/名义角后的电机目标。使能后由同一策略控制六电机，不先执行旧转腿脚本。

组合命令遵守 abs(vx × yaw) ≤ 2.06 m/s²：例如 1 m/s + 1 rad/s 均保留，3 m/s + 4 rad/s 会保留转速并把前进降到约 0.515 m/s。该限幅也必须在运行端一致。

RMCS 当前原生入口仍有准备姿态和 45° 失稳锁止；实车全 RL 起身需要专用入口允许恢复阶段的大倾角，并保留编码器/IMU 新鲜度、真实机械和力矩保护。仅替换旧 ONNX 不会启用任意姿态自起。

静站平滑在 ONNX 内，姿态扰动时会释放；无需再叠加部署低通。静站验收允许约 5 cm 内缓慢调整，没有为 actor 增加位置输入，因而不能保证无限时长位置不漂移。当前仿真关闭自碰撞，域参数范围属于鲁棒性假设，尚未经过车辆辨识。本包只有 Isaac Sim 证据，实际车辆测试和启动由用户执行。

## 本次仿真结果

两个独立种子，各 140 回合 × 12 s；候选和 1346 父模型逐回合世界原点、初态、命令、物理一致。

| 检查 | 最终候选 |
|---|---|
| 实际倒置后恢复并接续命令 | 24/27、21/23 |
| 实际左侧倒后恢复并接续命令 | 3/4、6/8 |
| 实际右侧倒后恢复并接续命令 | 5/8、3/8 |
| 精确 180° 初始姿态恢复并接续命令 | 合计 12/16 |
| 运动场景跑满 | 85/92、85/92 |
| 运动中倒地后恢复并接续命令 | 每种子 1 次 |
| 中速前后运动加左右转弯 | vx MAE 0.068–0.085 m/s；yaw MAE 0.076–0.140 rad/s |
| 静站 3–95 Hz 目标 RMS 相对改善的均值 | 87.06%、85.67% |
| 静站 3–95 Hz 实际轮腿运动 RMS 相对改善的均值 | 87.99%、86.73% |
| 稳定静站段最差回合 XY 位移 | 3.732 cm（3–12 s） |
| 闭链间隙峰值 | 0.752 mm；原保护阈值 3 mm |
| 失能时六电机输出 | 0 N·m |

恢复接续命令采用预先冻结的实用判据：回合跑满，最后 2 s 至少 95% 帧稳定，且 vx/yaw 误差低于 0.25 m/s / 0.4 rad/s。原严格连续计时结果仍在工作区原始报告中，不能把本结果理解为任意姿态百分之百恢复。

`quiet_comparison.png` 从 TensorBoard event 导出，展示三个高度的目标与实际运动。各物理量相对改善率先分别计算再等权取平均，没有把 rad 和 rad/s 直接相加。独立离线校验见 `offline_validation.json`。

## 已知限制

中低高度从开始到 12 s 的最差位移为 1.46–3.05 cm；从默认初态升到 420 mm 的前段可能移动 6.66–10.52 cm，后段才在 5 cm 内。该模型没有位置反馈输入，12 s 仿真结果不能保证无限时长的位置范围。

域训练来源见 `training_domain_history.json`。选中分支累计 313 次 robust 更新，实际消费 337 次（包含未采用分支的 24 次）；另有 16 次 v1 恢复初始化、1346 次已知运动父分支更新，更早预训练未知。最终静站头保留原 8 更新头，后续未改善的静站专项训练没有冒充最终收益；最后 16 次仅更新恢复头和 critic，冻结证明见 `frozen_recovery_validation.json`。

用户已确认实车策略 200 Hz；本轮没有实车 PD 频率读回，1000 Hz 是本次仿真反馈 PD 及匹配接口要求。需要按实际部署控制链核对，当前读取的旧源码常量不代表实车现状。

最终随机化压力测试见 `stress_validation.json`：独立种子 211322、140 回合 × 12 s，摩擦 0.3–0.5、域幅度 0.35；98 环境启用执行器/传感器域，42 环境保持名义执行器/传感器，地面摩擦仍按声明范围变化。实测执行器强度约 0.9475–1.0347 倍、力矩延迟最高 1 ms、策略观测延迟最高 5 ms。

低位 230 mm / 中位 305 mm 静站稳定段最差位移分别为 2.185 / 1.770 mm；420 mm 高位出现失稳和大幅漂移，最差 3.823 m，四回合中一个触发冲击保护、另一个仍持续漂移。高位未满足静站目标。运动场景 83/92 跑满，实际倒置后完整接续命令 20/28、左侧 2/4、右侧 3/8；运动中倒地恢复完整链为 0。闭链峰 0.808 mm，失能六电机峰值为零。该压力测试有明确失败，不能称全幅鲁棒性通过。

本轮实车候选建议先用 **305 mm**，中低高度范围为 230–305 mm；模型没有把输入高度硬夹紧到这个范围，需运行端按测试配置设置。420 mm 高位随机化静站和随机化运动中恢复仍是后续修复点。`test_limits.json` 记录本次证据边界。
