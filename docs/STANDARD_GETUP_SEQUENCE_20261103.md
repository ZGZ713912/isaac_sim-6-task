# 标准正向自起：先收腿和转移支撑，再伸腿抬身

本候选落实用户2026-11-03的动作要求：先收腿，再将左右轮子移至车身下方，最后协调轮速与伸腿，在小倾角下站起。只改变标准自起完成前的奖励和势函数；不执行定时动作或电机接管。候选验证结果另存于`reports/standard_getup_sequence_20261103/`，本页不将工程验证等同于学会自起。

## 已确认的问题

第500次更新模型的四朝向零PPO回放均翻过90°。一条轨迹在0.1s时腿长仍约36cm，却已从后方向下转动约35°；0.2s轮心接近车身下方时，车身已经倾斜约40°。这是回放观察，不是对单个奖励项的因果消融。

标准模式仍有`multi_pose_recovery`配置，因此进入了通用多姿态势函数分支，没有使用旧标准自起的收腿势函数。原v1密度虽包含倾角和角速度成本，却从启用开始同时评价305mm高度。单独关掉正高度奖励仍不足以取消提前抬身压力，因为高度误差成本和势函数里的抬身项也必须处理。

## 新合同

`wheel-leg-standard-getup-contact-v3`保留v1、几何候选v2的精确实现和验证入口；旧运行合同在`contracts/wheel_leg_prone_motion_v4_before_sequence_20261103.json`逐字节留存。v2只做过工程检查、未开始PPO；本次根据第750轮的接管诊断，正式候选补上真实承重与机身角速度条件。

* 用物理膝角小于约46°的程度提供收腿进度；这是离40°机械止点留余量的工程引导，既不是电机软限位，也不要求把腿推到止点。
* 同时检查轮中点与整车重心的支撑误差，以及每个轮心在水平车身前向上的误差，避免“一轮在前、一轮在后，中点看似对齐”的假支撑。
* 支撑误差从12cm到4cm时，以smoothstep渐变；倾角8°内完整生效，8–25°渐退，25°外不付抬身奖励。阈值仅用于奖励，不新增终止门或放宽验收。
* 高度门为上述支撑与姿态因子的平方。正高度奖励、宽高度误差改善量、势函数抬身进度都乘此门，没有另一路绕过。
* 几何到位继续提供摆腿引导；实际支撑另外要求左右轮分别承重。使用每个10ms策略区间内两个5ms物理样本的最小正向竖直接触力、最大轮缘离地间隙，不用最后一帧的接触脉冲冒充持续支撑。每侧承受整车重量15%时承重因子达到1；轮缘间隙1–3mm平滑退至0。它们仅是奖励系数，不修改接地验收或把接触力≤2N判成明显离地。
* 高度门再乘机身水平角速度的平滑收敛因子：0.3rad/s内完整启用，1.5rad/s以上不启用抬身。俯仰、横滚都计入，避免机身仍以约2.9rad/s转动时急于伸腿。真实承重与几何支撑形成后即释放收腿成本，允许腿在制动俯仰时微调；不要求再次收腿才能制动。
* 新增`recovery_capture_stability`密集奖励与对应势函数，随双轮支撑、低倾角及低水平角速度共同提高。角速度项使用有界质量函数`1/(1+(rate/0.6)^2)`，高转速时仍有收敛引导；原有全程倾角和角速度成本继续支付。不奖励轮速非零、空转或累计转数，也不新增原地位移惩罚。
* 高度误差以合同中的低趴参考高度173mm为零点，表示误差相对低趴姿态的改善。否则刚形成支撑便开始支付大额低高度成本，会产生不愿进入支撑区的奖励突变。
* 形成支撑前保留收腿误差成本，并对超过220mm的过早抬身付成本；形成支撑后释放收腿成本，让腿自由伸展，避免奖励把膝关节锁在折叠姿态。
* 倾角成本权重2→6，角速度成本0.02→0.1，均从主动自起开始生效。系数是待PPO验证的工程候选，未称最优。

这些门由当前几何、真实承重与姿态运动决定，没有按秒切换、隐藏阶段锁存、预设轮速或固定关节序列。势函数使用当前端点接触，密度使用完整物理区间；reset清空上个姿态残留的接触诊断后才初始化势函数。标准自起仍由同一网络控制四腿电机和两轮。此奖励鼓励所需顺序，不把每个关节的运动强制限定为一条轨迹。

## 记录和验证

原有`ProneMotion/reward_density_*`继续记录实际参与reward的密度；新增`recovery_fold_error`与`recovery_premature_height`。`recovery_height_error`在v2是相对低趴参考的改善量，可为正，不能继续按v1绝对负成本解释。

`StandardGetup/fold_score`、`support_capture`、`height_gate`、`support_error_m`、`physical_knee_max_deg`、`wheel_fore_aft_error_m`和`geometry_valid`由原RSL-RL TensorBoard logger记录，均只对未完成自起的主动样本取均值。采样代码不增加GPU到CPU同步。

v3再记录`StandardGetup/dual_wheel_bearing`、`body_horizontal_rate_rad_s`、`rate_readiness`、`capture_stability`及实际`recovery_capture_stability`奖励密度。原生校验独立从全部200Hz物理样本回算双轮竖直力、间隙与门值；实际覆盖数量单列。

CPU语义检查必须覆盖：准备阶段无提前抬身梯度、收腿和支撑的进度排序、支撑形成不产生负成本突变、支撑后可伸腿、双轮对消假支撑、无效编码器几何不给正引导、旧v1可复现。原生检查进一步核对真实返回reward、dt计价、主动区间mask、TensorBoard接线与物理保护；每个高度门区间的实际覆盖数量单独记录，不能用零覆盖的断言声称动态验证完整。

不改变初始倒地姿态、77/256自起份额、100Hz策略、200Hz物理及逐步反馈PD、64/32求解器、40–110°物理膝限位、5mm闭链峰值门、冲击保护、原技能/域随机化和冷测准入条件。actor35D/critic87D和六轴动作含义保持。v3不是旧权重的同合同续训；学习效果需要新actor、critic、空Adam在新输出目录从零验证，不能热切换正在运行的v1学习器。
