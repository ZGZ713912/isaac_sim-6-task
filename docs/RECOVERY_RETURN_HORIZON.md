# 恢复回报的时间尺度

`wheel_leg_self_righting_return_horizon_v1.json` 以几何抬升恢复合同为基础，
显式声明折扣指数衰减时间常数10秒、GAE残差核时间常数1秒。
策略周期为0.01秒时，`gamma=exp(-0.01/10)`，
`lambda=exp(-0.01*(1/1-1/10))`。GAE残差的核是
`(gamma*lambda)^k`。这些常数描述指数权重，不是回报或梯度的硬性截止时间。
critic的bootstrap和已有稠密势差仍参与学习，不能仅凭权重衰减断言失败原因。

PPO和势差塑形使用同一个gamma。该对照联合改变gamma、lambda以及塑形中
相同的折扣系数；不是单个数值参数的对照。它适用于包含原站立辅助角色的
恢复专用课程，不改变任何角色的出生、原恢复完成或稳定判据。

策略频率100Hz、物理1000Hz、PD与编码器200Hz、rollout64步、环境数、
有限训练的参数更新预算、网络和Adam初始化均由原入口及CLI保留。
回报时间常数增加不增加采样量，不延长现有运行。
旧合同不含新字段时保持原计算式和系数。

动作仍为既有编码器增量坐标，探索、奖励密度的数值权重与几何门控、
机械/冲量保护、七类倒姿和四类腿组合、独立冷评测门槛均保持。
新网络、critic和空Adam从零开始，不加载策略teacher或donor。
冷评测和能力准入继续使用原实际事件；折扣配置不能授予任何能力资格。
该细步合同不证明200Hz物理可迁移，也不执行16001连续交接。
