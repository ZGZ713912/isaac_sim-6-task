# 零速静站的局部轮式位移观测

`WheelLeg-ProneMotion-v4` 在原 v3 的 35 维观测中使用两个轮角保留槽
14、15，输入左右轮各自估计的前后位移，单位为米、乘以 20；原保留槽
31 表示该参考当前是否有效。网络结构仍为 35→6，同一个全可训练策略
控制四个腿电机和两个轮电机。观测语义已改变，旧模型只能用原任务播放。

训练入口默认 v4；play 未指定 `--task` 时从 checkpoint 合同识别版本，
显式指定版本不匹配会拒绝加载。训练仍为全新 actor、critic、空 Adam，
不支持 checkpoint 续训、teacher 或 donor。

```bash
bash scripts/train_prone_motion.sh --task WheelLeg-ProneMotion-v4 \
  --num_envs 256 --max_iterations 10000 --seed 105 \
  --run_name standing_odometry_seed105 --domain_randomization curriculum --headless
```

## 参考、几何与传感器

- 输入是底层驱动已展开、已转换减速比和符号的连续轮端角度。先以
  float64 减去本次零速请求的轮角起点，再进入 float32 传感器历史，
  避免把上电以来的巨大累计量送进网络。不要在 100Hz actor 端展开
  电机单圈编码器；底层必须满足自己的采样/转速条件。
- 局部角度和原有腿角、IMU、轮速经过同一个策略传感器延迟与噪声通道；
  v4 同时启用原有编码器噪声范围对两个轮角的扰动，不改变随机化范围。
- 前后位移使用已认证的 40–107° 闭链几何，补偿腿运动、被动连杆转角、
  轮心相对车体的前后变化和 IMU 俯仰。没有车体真值位置、真值速度、
  接触力、真实自起完成标志等 actor 输入。轮式估计不能消除打滑和横移误差。
- 平移/横移/转向指令均小于 0.001，电机使能，IMU 直立（15° 内），
  编码器估计的两侧支撑高度超过 0.20m，且 gyro <0.5rad/s、腿速
  <3rad/s、轮速 <2.5rad/s 连续 0.2s 后捕获一次参考。
- 本次零速期间的参考不随变高度、漂移、短暂无效样本移动。输出限幅
  ±1m，低通时间常数 50ms；限幅不重置参考。输出无效时两个位移槽和
  有效位为零，持续漂移后仍能恢复到原参考。
- 非零运动请求、禁用、episode reset 或严重倾倒（归一化重力 z>-0.5）
  释放静站参考；下一次有效静站重新捕获。普通行驶、原地自旋、倒地及
  尚未形成可测直立支撑姿态的自起不获得位置观测，原 IMU、轮速、腿角、
  动作控制路径保留。它不切换电机控制权，也不增加位置 PID。
- 静站请求内出现不合理轮角跳变或非有限轮角，该次请求的位置通道
  失效，不偷偷用新角度重设静站锚点；须结束该请求后才能重建。此检查
  不能识别全部漏圈、打滑或错误反馈，不替代既有硬件超时保护。

## 奖励与其他能力

v4 保留 v3 的 1cm 位移死区及 9cm 内的静站成本。在超过 9cm 后，仅
零平移且零转向、已结束自起的样本追加温和的距离项：

`-2 * log1p(max(anchor_error_m - 0.09, 0) / 0.04)`，单位为每秒奖励密度。

真实仿真 XY 锚点仍由原 reset/完成/驻停事件定义，不跟着轮式参考移动，
原始漂移和验收窗口不会被删除。高速、转弯、自旋、自起的奖励逐项保持。
角色份额、指令课程、100Hz 策略/1kHz 物理与 PD、轮侧模型、气弹簧、
力矩限制及域随机化范围保持原合同。

新增指标进入原 RSL-RL TensorBoard event：
`StandingOdometry/valid_fraction`、`reference_fraction`、`wheel_fault_fraction`、
`displacement_abs_m`、`displacement_peak_m`。它们是估计和观测接线证据；
减少真实漂移及保留高速/自起能力仍需新训练后的行为评测确认。

修改源码不会改变 Kaiser 上已经运行的冻结 v3；本次实现不停止或重启它。
