# 标准自起的观测尺度与全新网络初始化

候选合同 `contracts/wheel_leg_prone_motion_v4_physical_interface_v1.json` 只在 shape-priority 合同上增加 `learning_interface`。原 standing-v4 奖励、绝对输出轴编码器动作、动作尺度/裁剪、轮控、课程门、77/179 起始人口、10000 更新预算及物理不变；闭链只记录。

旧网络以 0.305 m 站姿为输出中心，而标准趴姿的编码器相差约 1–2 rad。早期共同转动力矩造成提前抬斜的因果回放见主工作区 `reports/standard_getup_leg_motion_repro_20261103/ROOT_CAUSE_REVIEW.md`。旧策略1750和2500的四朝向均实际恢复20秒超时；这不能归因为缺少倾角惩罚。

新网络的 policy35 前缀沿用环境声明的固定物理尺度，不再按站立期间的样本方差重新放大命令、编码器与上次动作。critic 的额外特权后缀仍使用从零开始的经验归一化。固定尺度不等于将所有输入裁剪到 [-1,1]；高度命令、编码器和上次动作保持原合法范围。旧 `ProneMotionModel` 保留，旧模型继续使用其原归一化，不能用新接口冒充恢复旧训练。

全新网络使用普通、可训练的 ELU 神经元路径：在站姿目标附近保留位置刚度，在远离站姿的趴姿处初始接近当前腿位置，避免站姿目标步阶。仅使用编码器物理单位与名义站姿推导初始权重，不指定动作轨迹。路径权重、偏置和其余网络都可学习；推理没有额外加上当前编码器，也没有固定的收腿/摆腿轨迹。将网络权重清零仍会请求固定名义目标，而非跟随当前编码器，这与此前取消的相对动作定义不同。轮子仍由网络输出绝对轮速。actor、critic、normalizers 和 Adam 均全新，不加载旧策略、teacher 或 donor。第一版全域编码器恒等初始化因削弱静站刚度，在原生对照中被拒绝，原始负结果保留。

这是针对已复现机制的候选修复。CPU 数学/梯度、原生接线以及早期动作改善不能证明学会完整自起；必须用新实验的冷测、真实20秒恢复窗口和完成后的保持段判断。
