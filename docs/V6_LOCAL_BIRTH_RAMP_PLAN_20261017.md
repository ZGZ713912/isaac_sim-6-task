## 候选实现边界

若独立确认仍支持该候选，实现独立命名的 nonstandard_start v2，本机 opt-in：

- 仅将选中的非名义出生从 200 ms 零力矩保持改成从首个物理帧起 100 ms
  线性最终六轴力矩渐入；第1帧增益0.05，第20帧为1，此后为1。
- 继续在原 PD、传输、响应和实际速度力矩限幅之后缩小力矩，不能放大输出；
  气弹簧、重力、接触、solver64/32、3 mm 门、5 ms 时序、原 profile 与出生概率不改。
- v1 完整 schema、合同及行为保持；不得为本机候选放宽 Kaiser/生产验证器。
- 选中 lane 的整个 100 ms 渐入区间从 actor/critic 样本中排除。新增独立的
  conditioning/mask 状态，不能为了排除样本而把 `holding` 伪报为 true（这会再次
  把输出清零）。返回状态的 bootstrap 按是否已结束渐入判断。
- 渐入时保留原策略动作历史，匹配已测 011/013 的真实输入；不能沿用 v1 的
  `held_interval` 清零动作历史来实现新 mask，否则不是已经测过的动力学轨迹。
- capture 1.5 秒、原可见命令 caps、课程 origin/概率和全状态恢复保持。
  非选中 lane、固定评测和旧 v1 必须不受影响。
