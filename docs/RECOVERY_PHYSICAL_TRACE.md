# 恢复冷评测的物理轨迹接口

`scripts/evaluate_self_righting.py --raw-physics` 在原独立冷评测上增加观察档案。正式接口为 `contracts/wheel_leg_recovery_physical_trace_v1.json`。默认关闭；不改变倒姿选择、缺失准入的失败分母、策略调用、恢复完成、终止、3 秒稳定窗口或原终止后退休环境重置。它不执行 WheelBipe16001 交接，也不把同检查点同样本的重测算作新独立总体。

观察器只准入标称域和原固定步长轮电机响应。物理回调位于原生 `simulate` 提交并由 `fetch_results` 完成、机器人状态更新之后，原接触归约之前。时钟是这些实际调用的完成记录，不是额外查询的引擎时间。独立接触查询写入观察器自己的缓冲区；控制器的反馈采样、滤波、延迟、动作和随机数均不由观察器推进。

每个 `batch_*/physical` 目录包含 `values.npy`、`clock.npy` 和字段布局 `manifest.json`。只有 `valid_frames` 行有效；预分配剩余容量不是零测量。`clock.npy` 使用 float64，包含批次相对时间、区间长度、原生步编号、已 fetch 完成时间、最后实际物理区间和所属策略帧。`values.npy` 使用 float32，布尔值为精确 0/1。完整原生关节顺序、刚体顺序和六电机顺序记录在顶层 manifest；四个腿目标遵从控制器自己的腿轴顺序，两个轮目标按左右顺序。

`state/joint_position` 和腿目标单位为 rad，关节速度和轮目标为 rad/s；资产中的气簧滑块关节保持原生 m、m/s 单位。根姿态为 xyz 和 xyzw 四元数，COM 速度保持原生六维顺序；重力方向无量纲、陀螺为 rad/s。`contact/force_world_n` 为每刚体世界坐标地面接触合力 N。`effort/*` 的六电机通道为输出轴 N·m；全原生关节物理通道中的滑块使用 N。物理施加力包括摩擦、气簧和云台等被动或其他贡献，不能当作六电机实际电流力矩。

`history/*` 在每个完成的物理步保存完整轮命令环形缓冲及 head、腿电机滤波状态、编码器 q/dq 环形缓冲及 cursor/tick、域力矩和传感器缓冲、云台状态及静止奖励滤波状态。各环形历史的维度在字段布局中声明，lane 为首维；环形次序没有重排为时间顺序。初始状态另存 `initial_state.npz`，不包含伪造的初始接触力、旧目标或旧电机输出。此档案不保存接触流形和求解器全部内部状态，不能当作可恢复仿真检查点。

`mask/enabled` 对应原物理区间的非禁用、非退休条件。`mask/scored` 对应外部原判分器仍在观察的案例；补齐并行环境用的重复 lane 不参与判分。策略输入、原始输出、各自上一动作及原诊断保存在 `policy` 目录。策略帧时钟中的 `dt_s` 为策略周期，`native_completed_dt_s` 为该帧最后一个完成的物理周期。

独立重积分从上述原始力和实际物理 dt 出发，先对每刚体的正 world-Z 分量积分滑动 20 ms，再按原组取最大。禁用和未判分区间不积累力，历史窗口仍按物理时间推进。`audit.json` 同时保留每刚体结果、组结果与原评测峰值的数值差；不改写原评测的值和通过判定。终止时保存所有同时出现的原故障和 timeout 标志，不能仅凭同时出现判断唯一原因。实际 16001 交接时间始终为 null，因为该评测入口没有交接。

运行前仍逐一验证训练的源码哈希。新增观察器、评测脚本和正式合同的哈希另存，避免把新增的评测实现说成训练时已经存在。CPU 测试只验证文件布局、积分、标记和回调语义；原生仿真还须另做准入，记录完整退出状态和所有失败尝试。
