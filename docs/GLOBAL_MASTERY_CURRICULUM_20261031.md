# v4全局评测解锁课程

用户已确认采用“URDF姿态静站→自起和低速运动→转弯/自旋→高速及组合变高”的依赖顺序。实现分支为`dev/leg-friction-v202-20261031`，正式任务仍为`WheelLeg-ProneMotion-v4`。一次全新actor、critic、空Adam的`learn(10000)`，无正式续训、teacher或donor入口，也不自动延长预算。此前只设自起门槛的v4合同保留为`contracts/wheel_leg_prone_motion_v4_recovery_20261031.json`；旧checkpoint继续使用其内嵌合同。

## 第一阶段和依赖

初始所有环境使用认证训练manifest的`nominal_joint_pos`和320mm名义根高度，零平移/转动指令；只在reset时做原有双轮接地修正。没有正向/复杂倒地初态、非零速度或高度变化请求。名义关节角不是305mm站立参考初态的近似替代，额外名义初态只从manifest在运行时派生，不改CAD、机构、原始252条初态库或机械限位。

默认每250次PPO更新，在空rollout边界进行一次确定性冷评测。站立过关后，分别加入四类正向自起、低速直行和静止变高，三条支线可并行；已经学会的技能持续混采。

| 技能 | 分级目标 | 解锁条件 |
| --- | --- | --- |
| 名义静站 | 320mm，两个独立heading，10秒评测 | 从零开始 |
| 正向自起 | 双前、双后、左前右后、左后右前 | 静站通过；四类分别使用原有留出评测门槛 |
| 复杂倒地 | 其他六类落面×四种腿组合 | 四类正向自起全部通过；同一RL连续翻正、自起，物理状态不中断 |
| 直行与启停 | 双向0.2、0.5、1、2m/s | 站立通过；1m/s还要求低速转弯和低速自旋通过；2m/s还要求1m/s制动通过 |
| 静止变高 | 低/高范围先50%、再100% | 站立通过；完整目标230/420mm |
| 四向转弯 | 前后±0.2/0.5/1/2m/s，yaw±0.12/0.3/0.45/0.6rad/s | 两档低速直行通过；更高档还要求对应直行档通过 |
| 双向自旋 | 10、30、60、100rpm | 两档低速直行通过；60/100rpm分别要求1/2m/s基础运动通过 |
| 高速制动 | 双向1、2m/s稳定段后在第12秒突发零请求 | 对应速度直行通过 |
| 行驶中变高 | 双向0.2、0.5、1、2m/s，同时230/420mm | 静止变高通过，且对应直行档已通过 |
| 转弯中变高 | 四向弧线各速度档，同时230/420mm | 静止变高通过，且对应转弯档已通过 |
| 自旋中变高 | 双向10、30、60、100rpm，同时230/420mm | 静止变高通过，且对应自旋档已通过 |

组合变高的高度指令从第7秒才开始变化，落在5–13秒的运动稳定请求段内。训练改变的是任务指令，六个腿/轮动作始终由同一个RL策略输出，没有预设腿轨迹或动作接管。

## 判定与复习

默认每个方向×高度组合的两个heading均须通过，不能用其他方向的成功抵消；成功率和连续通过次数可配置。速度误差上限同时受绝对和相对目标速度约束，低速测试不能靠原地站立过关。自旋检查实际车体转速及方向，100rpm档至少80rpm；制动检查连续停稳时间和实际制动后位移。高度、倾角、闭链、侧向速度、直线路径/自旋中心、几何离地连续时长共同进入判定。

轮子明显离地使用真实几何间隙>3mm及1ms累计连续时长；≤2ms保留诊断，不单独判失败，不以接触力≤2N替代明显离地。课程静站评测为10秒，不替代正式能力要求的完整30秒保持。正向自起门槛仍为每类4次、完成后连续站稳3秒。复杂倒地用48条非正向留出初态，24个落面×腿组合分别至少2次且独立过关。

每一技能保留当前学习档和已学低档复习，默认约70%当前档、30%旧档；全部技能可用后的名义权重为静站25%、恢复30%、直行10%、转弯10%、自旋10%、静止变高3%、行驶变高4%、转弯变高4%、自旋变高3%、制动1%。有限环境数取整且每个可用技能至少1个环境。未解锁技能的份额分配给当前可学技能，初始静站为100%。恢复池在四类通过后直接使用40%正向、60%其他落面的固定复习比例，不再按2000/4500等轮数切换。

所有名义技能及复杂倒地通过后才进入逐级域随机化。沿用现有域种类、范围和强度顺序；忽略旧表的固定更新数，每档至少训练250次更新，并要求当轮全部已学技能、四种正向自起和复杂倒地复评通过才升档。遗忘、失败或缺项阻止升档。10000轮结束前未掌握的技能/未到达的随机化档如实记录，不追加训练或默认通过。

## 接口与证据

并行训练环境数通过`--num_envs`选择，支持20–512，合同默认仍为256。512环境、每环境64步时，每次PPO更新包含32768个rollout位置；正式总预算仍为10000次更新。512个独立世界继续使用完整车体和地面的原生碰撞隔离，不通过改变物理模型或课程门槛扩大环境数。

`--curriculum-eval-every`、`--curriculum-success-rate`、`--curriculum-required-passes`配置全局评测；正向四类的独立门槛继续通过`--recovery-gate-*`配置。阶段参数、阈值和依赖在合同`global_curriculum`中显式保存。`--domain_randomization off`保持名义环境；`on`在名义技能全通过后直接请求指定随机化强度；默认`curriculum`逐档评测。

评测不进行optimizer更新，不重建learner，逐值检查actor、critic、Adam未变且storage为空；结束不完整训练回合并刷新观测后继续原learn调用。每个global冷评测保存逐试验判定及原生轨迹NPZ，更新轮数、单位、判定和派生状态写入checkpoint/progress。训练曲线继续由既有TensorBoard logger记录`Curriculum/<skill>/cold_pass`、`mastered_levels`及域索引，不新增本机服务。

原有70秒最终固定能力矩阵继续保留，另加入各动作同时变高度及突发高速制动场景。课程准入、短时原生接线和CPU测试均不授予完整能力或实车资格。独立续训研究脚本采用同一全局课程，但产物仍标记`continuation_validation_only`，无法进入正式10000轮训练。
