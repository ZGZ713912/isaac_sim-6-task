# 自起期间允许平移，完成后保持当前位置

用户2026-11-03要求：自起可以发生必要平移，起身成功后才保持位置。新实验显式选择 `contracts/wheel_leg_prone_motion_v4_free_translation_v1.json`；历史合同继续保留原行为。

新增 `getup_translation` 合同仅改变位移约束：尚未完成自起时，位置代价为零，相对出生点超过35厘米只记录，不触发终止、失败罚分或课程淘汰。35厘米字段保留为诊断参考，不改成一个更大的隐藏硬门。实际XY位移及超参考比例写入 `GetupTranslation/active_displacement_mean_m`、`active_displacement_peak_m`、`over_reference_fraction`，沿用TensorBoard更新步；峰值tag为每策略步峰在rollout内的均值，原始轨迹保留实际峰值。

当前standing-v4的自起位置代价原本就是零，旧 `rise_position` 已由独立自起奖励分支替换；本次明确关闭通用路径中的该项，避免以后退回旧分支时再次出现。旧模型1500四朝向确实在约1秒触发35厘米位移终止；2000则都在20秒主动恢复期限超时，停在约22厘米高度、14–15度倾角、双膝约41度的低姿态。本改动不证明后者已经解决。

位置保持和静站观测仍按实际起身完成后的位置工作。既有 `course_anchor` 在真实完成事件重设，`QuietStanding` 仅在恢复完成后首次静站请求建立参考；自起位移不积累成起身后要退回出生点的误差。静站位置和速度代价、完成条件、原保持段、倾角/角速度、20秒主动期限、冲击/机械/非有限保护、普通倒地判据和课程均保持。速度收敛与累计位移是不同量，本次只解除累计位移限制。

闭链继续只记录；物理膝40–110度、40Nm形状优先、100Hz策略/200Hz物理与PD、64/32求解器、绝对编码器动作及既有学习接口保持。新合同须全新actor、critic、normalizers和空Adam，不作为原合同续训。
