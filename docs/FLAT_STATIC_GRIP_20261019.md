# 地面0.2–0.5下的静站续训

当前地面材质按用户最新要求，逐环境均匀随机0.2–0.5；轮子0.1、机身0.25，
静摩擦和动摩擦相同，采用`average`组合。所有材质在环境建立时采样，reset不重采。
当前基线使用封存1328策略，50 Hz策略、1000 Hz物理/PD和4096训练人口保持。

旧0.2–0.3地面回放中，23 cm静站最大漂移3.149 cm，超过3 cm门限。
在三档静站的6000帧实际输入中，1328策略唯一可训练的轮速分支门控全部为0。
该训练范围无法通过PPO修正静站；只改变摩擦参数并继续训练无助于解决这个限制。

新增`StaticGripActor`使用全部相同的参数名、参数顺序、缓冲区和前向计算，
进入训练前与1328父策略函数完全一致。它仅开放现有`static_feedback`的1126个参数；
原始ONNX、命令、运动反馈、高速反馈、轮速头、std及其Adam保持冻结。
新版本v7显式标识静站参考允许适应，原v5/v6仍严格拒绝被改过的静站参考权重。

静站分支仅在零命令及很低命令的混合区间参与输出；在相同观测且
`abs(vx)>=0.1`或`abs(yaw)>=0.2`时，运动输出函数保持父策略。
这不证明闭环无退化，起停、转向、三档静站均需要真实回放。
ONNX导出和checkpoint读取已覆盖适应后的静站权重及混合区间数值一致性。

本次小训限定2次critic预热和8次actor更新，actor学习率从0.001降至0.0001，
critic保持0.0005。完整恢复父actor/critic/std/Adam/RNG/消费后再应用声明的学习率，
不重置已有学习状态，不退还历史试验消费，不自动追加长训。
原地面0.2–0.3的`static_grip_candidate001`只做过CPU准备，未启动PPO；
