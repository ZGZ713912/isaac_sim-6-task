# 统一自起/运动策略：2026-10-23本机迭代

**当前仍未达到大训练和新实车交付的准入条件。** 已经验证明显减振及一部分纯RL自起；剩余主要问题是随机化静站的尾部漂移、运动强推倒后的恢复，以及部分侧倒起身后的持续站稳。所有下述行为证据来自Isaac Sim；没有实车运动或Kaiser改动。策略200Hz，物理/反馈PD 1000Hz。

## 当前组合验证与账本

044仅选择040的高位反馈及其Adam moments，恢复干净中低位，不新增PPO。23,600条真实输入隔离检查通过；新PT SHA `58bd90857a29a8f30cced051623d47fd16f25efc9f77dbae5fdb3aa553a00101`。140回合原生完整复测已完成：倒置/左右侧倒的起身和实用接续计数、普通运动86/92、强推接续1/8均与032相同。高位实际腿/轮振动下降30.25%/34.97%，但最差全窗6.146cm，仍只有2/4在5cm内，因此不授长训或交付资格。

043的协调反馈方向仅完成只读导数原型，尚未在原生actor中实现。后续要用可证伪的有界测试验证协调平衡反馈，避免继续单纯提高轮反馈增益；运动跌倒也需独立检查恢复介入时序及样本曝光。机械3mm和正式双种子判据保持。

045已实现一个不同于043指令原型的协调状态分支：只读取既有IMU/腿角/速度、同腿两轴新增共同转动、两轮独立修正，不增加上一帧动作递推。204值零初始化且冻结其他actor，92项CPU检查及15,600条真实输入零函数迁移通过。32更新短训及配对48回合复测已完成；只有新增六张量和critic更新，旧actor/std及其Adam不变。中位最差漂移改善33.6%，但低位变差、高位5cm内0/16，整体拒绝。高位实际腿/轮3–95Hz下降44.1%/32.4%，减振仍不能替代漂移目标。图`standing_coupled045.png`来自原TensorBoard event。

047仅将045的三个新增bias置零，其余权重/critic/Adam/RNG保持，并清除对应三个bias的Adam；0新PPO。8,400条真实输入中，quiet之外7,481条动作完全相同。相同48回合原生消融已正常完成且初态全部匹配；高位全窗仍0/16在5cm内，低位也比干净基线差，中位去bias后反而退化，因此拒绝。仅去掉新bias不足以解决问题；姿态等特征仍可形成近常量输出，不能声称已排除全部常量补偿机制。

分段指标单独写入原TensorBoard event：045中位末9s最差净移动14.47→9.41cm，但高位既有启动偏移也有持续漂移，不能把16条全窗超线解释为16条都持续匀速运动。047高位后段5cm内8/16，全窗仍0/16；分段参考原点不同，两种统计分别保留，原准入不放宽。对照图`standing_bias_ablation047.png`和数据`standing_segments047.json`。
