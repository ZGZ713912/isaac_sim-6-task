## 结论与边界

旧长训同时使用`domain_scale=0.35`和`gap_severity=0.6→0.8`。两者不相乘：先执行基础scale，再由gap profile覆盖质量/惯量/COM、增益、编码器偏置及IMU安装/晃动；白噪声等仍按0.35缩放。将它概括为“全部只有35%随机化”不准确。932次新增PPO结束时最高实际severity为0.8，计划中的1.0阶段没有训练到；固定压力评测本身另用severity1.0。

**有理由怀疑组合域过难、部分扰动模型偏保守，但没有证据把退化全部归因为范围太大，也没有实测最优强度。** 训练后反馈变化参与退化已得到配对实验支持；尚缺相同随机初始网络、预算和样本时域下的分组/强度训练对照。接下来用可解释的组和独立名义复习观察变化，不把“开更多DR”直接当成更适合实车。

## 哪些耦合值得优先排查

1. **IMU晃动与白噪声不是同一种难度。** 正弦晃动会产生一致的附加gyro：单轴峰值上界`振幅rad × 2π × 频率Hz`。0.4°/8Hz对应约0.3509rad/s（20.11°/s），约为0.0035rad/s白噪声σ的100倍。这是包络上界，不是每个样本实际达到、不是RMS，也不是已证明的退化因果。需把安装静态偏角、有色晃动、普通gyro白噪声分别测试，并用实测IMU频谱校准。
2. **强度与P/D共同改变闭环。** 腿P/D先随机，随后电机强度乘作用力矩。未饱和时等效P比例范围约0.7392–1.2992，D约0.6384–1.4384；相对名义D=2.5约为1.596–3.596。不能只读“D±24%”。独立惯量再乘各刚体质量，使实际惯量比例包络约0.7728–1.2528。端点不代表所有极值在同一环境出现。
3. **编码器偏置的两路不一致。** 策略位置偏置和底层PD位置偏置独立抽样；停止阶段差值可到0.008rad。单独±0.004rad在名义P=160下对应0.64N·m的位置力矩偏置量级。这是模拟的额外测量分歧，是否符合实车策略/PD读取同一编码器的事实应单独对齐。新配置暂明确保留并披露此模型，不冒称已经完成真实传感器一致性建模。
4. **名义复习不足和学习目标的影响不能忽略。** 改动多个域再长期更新站立/运动分支，会改变已有反馈。原奖励对低于6rad/s的静站激振覆盖不足等旧问题已有记录；不能通过删掉DR掩盖训练目标或反馈的问题。

当前009按v2中高度7/7通过，微小约0.0036°RMS不再阻塞；它没开DR，不能将它与上述旧模型的不同训练、初态、架构和域直接当作因果A/B。

## 现在可以怎样调节

可编辑入口：[wheel_leg_randomization_study_v1.json](../contracts/wheel_leg_randomization_study_v1.json)。七个组以名称单独设0–1半径比例；`strength`再乘一次所选组比例，**不再经过旧gap覆盖，也不会被旧domain_scale再次缩放**。时间延迟用独立的整数范围，避免强度经round后突然从0跳到5ms却被当作连续渐进。旧配置和旧轨迹均保持。

| 新准备的profile | 单独研究的内容 | 实际候选范围 |
|---|---|---|
| `nominal` | 名义复习 | 所有组0，固定地面/时序 |
| **`sensor_first`，默认研究项** | 观测白噪声0.25、编码器偏置0.2 | 角度σ0.00025rad，策略/PD各±0.001rad；腿/轮速度σ0.0125/0.0625rad/s；gyro σ0.0025rad/s、偏置±0.00375rad/s；重力分量σ0.001 |
| `imu_alignment_only` | 安装偏角0.2 | roll/pitch±0.6°、yaw±0.2°，无晃动 |
| `imu_wobble_only` | 平台晃动0.2压力项 | 0–0.1°、1–8Hz；单轴gyro上界0.0877rad/s，单独研究 |
| `actuator_only` | 增益0.25 | 电机±5%、P/弹簧±3.75%、D±7.5% |
| `rigid_body_only` | 刚体0.2 | 质量±2%、独立惯量±4%、COM x/y/z±3/1.6/2mm |
| `friction_only` | 摩擦0.25 | 地面0.45–0.5，有效轮地0.275–0.3 |
| `combined_light` | 噪声+偏置+静态IMU偏角+轻增益/刚体 | 上述轻量组组合；不加平台晃动、延迟和低摩擦 |

新研究项共享名义域比例先设50%；默认`sensor_first`地面固定，所以其中名义域也有名义地面。启用`friction_only`等时，地面仍按既有接口覆盖全部环境，合同明确披露，不能继续把50%称作完整名义场景比例。

例如将`profiles.sensor_first.observation_noise`从0.25改为0.15会降低白噪声组，编码器固定偏置仍由`encoder_bias=0.2`独立控制。把`imu_wobble`设0不会取消gyro白噪声；改变`strength`不修改名义人口或独立时序配置。所有最终范围均写入生成任务合同及`randomization_study.resolved.json`；后续实际训练通过现有RSL Logger记录`DomainStudyConfig/`，审计使用`DomainAudit/`和明确标为未训练的`DomainStudyPrepared/`。
