# 编码器增量恢复动作接口

`contracts/wheel_leg_self_righting_encoder_increment_v1.json`显式选择本接口。
它是独立实验接口，不与旧绝对位置恢复动作或WheelBipe站立动作混用。
它没有通过自起、低冲量或硬件验收。

策略六个输出按`左共同转动、左相对变化、右共同转动、右相对变化、左轮、右轮`排列。
35D观测保留编码器/IMU/命令原有物理尺度；22..27槽位保存该策略自身的上述上一动作。
腿的四个原始输出裁剪到±1；轮速尺度、裁剪、力矩保护保持原合同。
出生、禁用和使能边界的动作历史为零。零腿动作表示保持反馈编码器姿态，
超出相对软域时仍有下面的有限内向修正；零轮动作仍为零轮速目标。

每侧令`s`为左+1、右−1，`d=s*wrap(q_aux-q_hip)`，`m=q_hip+s*d/2`。
策略周期`T`内，目标共同角增加`2*T*a_common`，相对角增加`2*T*a_relative`。
相对角投影使用当前认证气簧模型的`relative_soft_limits`及其margin，
随后把相对角修正限制在±`2*T`。软域内目标留在软域内；域外只能有限内返，
不会为了立即落入软域产生一个很大的目标跃变。输出为`m−s*d/2, m+s*d/2`，
两轴共用髋编码器的转数。这里的`d`是两个电机轴的相对坐标，不是机械内膝角。

参考来自现有低层PD编码器反馈的最后一次样本，不额外读取真值或推进反馈时钟。
目标在每个策略周期计算一次并保持；没有累积目标状态。反馈`observe()`只在新PD计算时
调用，所以本接口在任何物理步之前按实际PD周期构造反馈组件，然后由原出生reset填入编码器历史。
100Hz策略、200Hz PD、1000Hz物理时，首次目标来自reset样本，此后标称边界样本年龄为5ms；
随机采样/延迟保持其既有毫秒配置，并按真实5ms采样周期量化/插值。
该构造是独立新环境的初始化，不能用于热换一个已经运行的控制器。

100Hz时，共同和相对增量各最多0.02rad，每个电机目标相对反馈样本最多0.03rad。
这是目标位移界，不是实际腿速限制；惯性、阻尼、气簧和延迟仍可造成超速或饱和。
全新actor使用普通可训练的小随机末层和零输出偏置，不套用旧绝对位置的编码器保持权重。
共同/相对原始探索标准差均0.8，裁剪前对应1.6rad/s；轮速标准差5rad/s。
初始化和实际采样分布共同使用0.003..1.0的显式范围。

原势差、接触冲量、实际恢复/稳定事件、终止与课程门槛保持原定义。
动作变化成本仍是六个原始坐标的均方变化，使用原参考时间缩放；现在其腿部坐标是共同/相对增量，
因此该成本不能解释为旧绝对目标的弧度变化，也不应跨接口直接比较reward。
既有静止滤波器输入使用实际四轴目标弧度和轮速目标，不把共同/相对原始动作乘旧0.25尺度冒充位置。
目标编码器位移、原始裁剪比例及实际反馈周期接入现有TensorBoard logger。
选择后续预算须依据独立实际行为；原生接线通过不表示学会自起。

## 显式较宽增量版本

`contracts/wheel_leg_self_righting_encoder_increment_range_v1.json`选择解码器v2、
学习接口v3与探索v3。三者必须匹配；旧v1的解码、初始化和配置保持原定义。
新版本仅把共同目标率从2改为8rad/s、相对目标率从2改为4rad/s。
100Hz时共同增量最多0.08rad，相对增量最多0.04rad，每电机相对反馈目标位移最多0.10rad。
软域投影、域外内返和共享转数使用同一公式及新的相对增量界。
原始探索标准差仍0.8，裁剪前的物理目标率标准差相应为6.4和3.2rad/s；
轮速、反馈时钟、机械/力矩保护、验收、奖励及出生课程没有修改。

该版本用于比较动作范围对支撑捕获与抬升的影响。冻结反馈、零速度、不含气簧和响应时，
腿PD160的位置项对应每电机最多16N·m、每侧共同电机力矩和25.6N·m；
这是受限定的目标预算计算，不是实际电机力矩上限或恢复所需力矩的估计。
目标率不是实际关节速度保护；扩大范围也可能增加冲击或故障，必须完整保留失败分母。
两个版本使用独立全新网络和空Adam，旧策略不能作为teacher、donor或初始化。
