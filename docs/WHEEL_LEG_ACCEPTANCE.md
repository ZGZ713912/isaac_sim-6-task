# 轮腿策略长期验收要求

2026-10-26按用户要求建立。机器可读版本：[wheel_leg_acceptance_requirements_v1.json](../contracts/wheel_leg_acceptance_requirements_v1.json)。本文件是后续训练、观察、修复与汇报共同使用的能力清单；不得因训练困难而删除项目、降低自旋速度、放宽静站接地，或只汇报有利场景。用户以后明确修改要求时另建版本，历史结果保留原判定。

当前实测与证据入口：[2026-10-26能力盘点](WHEEL_LEG_CAPABILITY_STATUS_20261026.md)。此处保存长期要求，具体checkpoint的成绩放在带日期的报告中。

## 用户明确固定的目标

- 静站从开始的第一物理采样起双轮连续接地承重，接地率必须100%，不接受离地或失载宽限。轮子时接时离、靠腿抖动保持身体直立均不通过。
- 高速原地“小陀螺”目标100转/分，最低80转/分，顺逆时针均要验证；同时检查是否离开原位置、持续漂移或翻倒。100rpm=10.47198rad/s，80rpm=8.37758rad/s，量测对象是车体实际yaw角速度。
- 基础动作必须流畅，理想状态为丝滑；四腿、两轮、力矩和接触都要观察，不能只看车身是否倒下。
- 初态自起、运动中突然翻倒后的快速自起、稳定站立、低高速直行/转弯、自旋、三种工况下变腿高以及高速急停均为长期必测能力。
- 后续训练从零开始：全新actor、critic及空Adam，不续训旧策略，不用旧策略作teacher或donor。历史checkpoint只作只读比较。明确记录的名义机械初始化先验与旧学习权重分开。

## 必测任务与量测口径

| 编号 | 固定任务 | 每轮必须量测和披露 |
|---|---|---|
| R01 | 初始姿态自起 | 前倒、后倒、左右侧倒、完全倒扣及左右腿不对称；真实落稳姿态；从接管到起身/首次站稳/持续站稳的时间；成功/总数；冲击、保护终止、腿速峰值；起身后跟随命令 |
| R02 | 运动中突然翻倒并快速自起 | 前进、后退、左右转弯和自旋中施扰；记录是否真正倒下、倒下时刻、恢复时刻、稳定保持及恢复原命令的时间；未倒下的抗扰成功不得算翻倒自起成功 |
| S01 | 三高度静止站立 | 230/305/420mm；每1ms双轮承重、失载总ms/次数/最长连续ms；真实XY最大位移、终点偏移、末段向外趋势；姿态、实际高度、腿轮速度与振动 |
| M01 | 低速前进/后退直行 | 请求、生效命令、实际速度三者；MAE/RMS/峰值误差；起步和反向延迟；横向偏移、航向误差、滑移、接触及流畅度。近零低速不能由1m/s成绩代替 |
| M02 | 高速前进/后退直行 | 正反分别统计速度跟随、直线横向偏移/航向累积、起步和稳定时间、摔倒与接触；不能只看速度均值接近请求 |
| M03 | 80–100rpm原地自旋 | 顺逆时针，目标100rpm、最低80rpm；实际车体转速稳态分布/波动、加速时间、XY最大半径/终点半径/末段漂移、自旋停下后的稳定；全高度及变高组合 |
| M04 | 前进/后退同时左右转弯 | 四象限全部覆盖；同步速度/yaw误差、转弯半径、轨迹偏差、相位延迟、接触、腿轮协调；披露命令裁剪或横向加速度投影 |
| H01 | 静止时改变腿高度 | 低↔中↔高双向升降、阶跃和连续变化；高度误差/超调/响应/稳定时间、实际虚拟腿长与角度、XY漂移、100%双轮接地和抖动 |
| H02 | 运动时改变腿高度 | 前进/后退及四象限弧线中升降；同时检查高度、速度、yaw和轨迹，不能以高度跟上掩盖运动失控 |
| H03 | 自旋时改变腿高度 | 两方向及目标80/100rpm下升降；同时检查转速、中心漂移、倾角、接触和流畅度 |
| B01 | 高速突然停止 | 高速前进与后退各直接给零请求；量测请求至实际响应延迟、停下时间/距离、越过停点、回弹/二次前冲、pitch、接触、力矩与腿轮运动；低速停住不能代替高速急刹 |
| Q01 | 全任务动作流畅度 | 目标和实测关节角/速度、加速度/jerk、实际力矩与slew；腿角及轮速3–95Hz和原生1kHz可观察的95–450Hz分量；接触失载脉冲；峰值及超阈样本数。与命令相关的正常大动作不能无条件当噪声惩罚 |
| D01 | 随机化与鲁棒性 | 名义域、逐项改变与组合域；独立种子/参数抽样/摩擦；出生与运动中扰动；按任务和域分别报告成功分子/分母、长尾、最差例和失效类型 |

初始完全翻倒时允许自起所需的身体/腿支撑接触；“从静站开始100%双轮承重”不能机械地用于自起尚未完成的倒扣阶段。必须完整保存自起过程，再单独检查它进入站立之后的连续接地与后续运动。

低/中/高固定高度的分别保持，不能替代高度变化测试。身体变直不能替代站稳，站稳不能替代起身后继续运动。任何一代的综合通过必须来自同一个准确checkpoint，不能把多个分支的最好成绩拼在一起。

## 已有数字与尚未规定的数字

沿用已有明确的静站位置参考：低/中位全窗最大XY偏移≤5cm，高位≤10cm；高位30s测试的末10s平均半径≤max(5cm,峰值的80%)，末段向外径向趋势≤1mm/s。有限30s不能证明无限时间不漂移。闭链间隙上限仍3mm。

**3mm闭链限制不是允许轮子离地3mm。** 旧协议中的出生0.2s宽限、只看末段稳定或平均承重率，都不能覆盖本轮用户的首1ms起100%静站接地要求。当前仿真接触观察器用两轮接触力模均严格>2N判定承重，并同时保留轮缘几何间隙；失载即计入失败，不得通过降低阈值或忽略短脉冲改成通过。

用户尚未给出“快速自起”的最大秒数、所有速度档的误差/响应时间、直线横向误差、自旋中心允许半径、升降超调/稳定时间、急刹距离/时间以及全部工况绝对流畅度阈值。本文件固定这些任务及量测方法，不能伪称用户已同意某个新数字。后续具体评测应在运行前冻结工程测试档位、窗口和数值门，未量化的项目持续披露数据，不能自动算综合通过。

现有8s×21场是静站基础试验，不是完整验收。基础通过后继续原30s、多种子和新域确认；历史115的较宽恢复/存活门也不能代表本文件要求的可靠、快速、流畅的综合能力。

## 髋膝与轮速应共同控制

用户提出的控制方向保留为长期设计要求：让髋膝改变轮心相对车体的前后位置，利用虚拟单杆与驱动轮一起调节加速、减速、反向和pitch。不得把所有动作简化成只调轮速，也不能通过冻结腿来换取表面安静。

每侧用当前闭链几何得到髋点H与轮心W在车体中的位置，令`r=W−H`。在已统一左右符号、x向前/z向上的坐标系中，可观察虚拟腿长`l=sqrt(r_x²+r_z²)`与虚拟杆角`theta=atan2(r_x,−r_z)`；相应雅可比从当前机械模型求取，不能从旧模型抄电机角符号。记录两侧轮心前后位移/速度、杆角、长度及其导数，与实际轮速、车体pitch/pitch rate、真值XY速度、接触/滑移和施加力矩对齐。

加速或急刹时，策略需要协调轮驱动力和支撑点前后移动，保持重心、接触与pitch可控。静止时则不应持续注入高频能量。奖励和流畅度观察应结合任务阶段与实际跟随误差，不能不分工况地强罚所有腿运动。比较需要相同初态/域/命令的真实闭环证据，网络里有四腿输出或动作范围足够大都不能证明已学会协调。

当前009仍有四腿位置目标与两轮速度输出；它只分离神经网络中腿输出对原始腿速的直接通路，实际PD仍使用真实腿速。该结构没有实现新的虚拟杆动作接口或证明急刹协调有效。后续如改为虚拟杆参数化，应先验证闭链可达性、连续性、力矩/速度边界及PPO实际采样/概率一致，再独立从零训练。RMCS倒扣查表只作为可行姿态/覆盖参考，不引入执行自起轨迹的脚本/FSM替代六轴闭环RL。

## 证据和比较规则

1. 每个结果绑定checkpoint SHA、训练来源、源commit/归档、初态、参数抽样、种子、命令与时间窗口。不同冷/暖启动、协议或课程范围分开报告。
2. 新训练先验证并提交源码/合同，再冻结启动；原生任务串行。训练累计消费保留，失败不能抹去。后续一律从零训练。
3. 名义域通过与随机域通过分开；随机化代码存在、范围很大或训练轮数很多都不证明鲁棒性。参数区间需区分实测辨识与研究假设。
4. 记录请求、生效和实测命令。把3m/s+4rad/s自动投影成0.515m/s+4rad/s后，只能评价生效命令的跟随，不能声称完成原请求。
5. 训练曲线统一复用RSL-RL TensorBoard events；原生轨迹、checkpoint、合同、评测判定和SHA回执承担机器验收。训练均值接近100%不能替代每1ms全程100%接地。
6. 真正的原生峰值从所有物理样本求最大值。旧`ScratchStanding/leg_speed_peak_rad_s`经rollout logger平均后不是整轮真峰值，不能拿它排除50rad/s；固定评测的1ms原始dq峰值另算。
7. 未测、未训练、没有阈值、初态配对不完整、实车未验证都必须明示。仿真、离线接口检查与实车效果分别记载，不能相互替代。
